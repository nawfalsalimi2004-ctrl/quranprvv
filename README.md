# سيرتي برو | CVPro - منصة بناء السيرة الذاتية الذكية

منصة متكاملة واحترافية لبناء وتصميم السير الذاتية باللغة العربية والإنجليزية، متوافقة بنسبة 100% مع معايير أنظمة التوظيف الدولية (**ATS**)، ومزودة بمساعد ذكاء اصطناعي، واستوديو لتخصيص المظهر والقوالب، ولوحة تحكم للإدارة (Admin Dashboard).

---

## 🌟 الميزات الرئيسية

- **⚡ محرر السيرة الذاتية التفاعلي**:
  - البيانات الشخصية مع رفع الصور ونماذج جاهزة.
  - **مساعد الصياغة بالذكاء الاصطناعي (AI)**: اقتراح وتوليد النبذة المهنية بنقرة واحدة بحسب المسمى الوظيفي.
  - الخبرات المهنية مع تنظيم نقطي للمهام واقتراحات أفعال قوية.
  - المؤهلات الأكاديمية والتعليم.
  - المهارات التقنية والشخصية مع مؤشرات نسبة مئوية ومستويات الإتقان.
  - المشاريع، اللغات، والشهادات المهنية المعتمدة.
  - فحص قوة السيرة لمعايير ATS (ATS Strength Score) مع قائمة نصائح فورية.
  - حفظ محلي فوري (Local Storage)، وتصدير/استيراد ملفات JSON.

- **🎨 استوديو مخصص للمظهر والقوالب**:
  - 5 قوالب فخمة: (العصري Modern، التنفيذي Executive، الكلاسيكي Classic، الإبداعي Creative، والمبسط Minimal).
  - لوحات ألوان متعددة مع إمكانية اختيار أي لون مخصص (Hex Color Picker).
  - خطوط عربية مدمجة: Cairo, Tajawal, Almarai, Inter.
  - تخصيص إطار الصورة، والتباعد، والاتجاه (عربي RTL / إنجليزي LTR).
  - شاشة معاينة حية متزامنة في نفس الوقت.

- **📄 المعاينة والطباعة (PDF Ready)**:
  - محاكاة مقاس A4 القياسي للطباعة بدقة 300 DPI بدون أي عناصر تحكم ظاهرة.
  - خيارات التكبير والتصغير (Zoom).

- **🔐 نظام الحسابات والمصادقة**:
  - تسجيل الدخول وإنشاء الحساب.
  - إخفاء بيانات وصلاحيات المسؤول بالكامل عن المستخدمين العاديين.
  - حظر الوصول غير المصرح به للوحة الإدارة (403 Forbidden).

- **🛡️ لوحة تحكم الأدمن (Admin Dashboard)**:
  - إحصائيات عامة ورسوم بيانية لاستخدام القوالب والمستخدمين.
  - جدول إدارة المستخدمين (تغيير الحالة: نشط / معطل، تغيير الصلاحية، وحذف الحسابات).
  - إدارة القوالب وتفعيلها أو إيقافها، وتحديد القوالب المميزة.
  - سجل نشاطات وأحداث النظام (Audit Logs).
  - إعدادات الصيانة وتفعيل الميزات.

## 💻 التقنيات المستخدمة

- **React 18** + **TypeScript (TSX)**
- **Tailwind CSS** (تصميم عصري متجاوب + دعم RTL كامل)
- **Vite** (أداء سريع وبناء فائق الخفة)
- **Lucide React** (أيقونات واضحة وعصرية)

## 🚀 طريقة التشغيل محلياً

```bash
# 1. تثبيت الحزم

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء المشروع للإنتاج
npm run build
```
